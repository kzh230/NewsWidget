# NewsWidget
News Widget for Android

## 소개
안드로이드 용 뉴스 위젯 전용 앱입니다.
기존의 뉴스 위젯들처럼 무겁거나 복잡하지 않고, 심플하며 가벼워서 부담없이 사용 할 수 있습니다.

## 설치법
1. Releases에서 최신 버전을 다운로드 합니다.
2. NewsWidget_v.1.x.apk 파일을 실행합니다(.apk 파일 설치 시 디바이스의 보안을 위한 차단을 해제 할 필요가 있습니다).
3. 바탕 화면을 길게 눌러 NewsWidget 이름의 위젯을 찾아 설치합니다.
4. 화면은 상하좌우로 늘릴 수 있습니다.

## 사용법
1. 위젯 화면의 아무곳이나 터치하면 뉴스가 바뀌며, 뉴스 자동 바뀜은 지원하지 않습니다(구글 정책이나 배터리 문제 등으로 적용 안함).
2. 우측 상단의 "뉴스 보기 >"를 누르면 구글 뉴스 앱(설치 시)이나 기본 웹브라우저가 열리며 해당 뉴스로 연결됩니다(선택 가능).
3. 구글 뉴스 앱을 설치하면 더 깔끔합니다(웹브라우저는 뉴스마다 새창이 열림, 물론 설치 안해도 됩니다).
4. 뉴스 목록은 15분 간격으로 구글 뉴스 홈에서 받아 리셋됩니다.
5. 배경색 변경이나 투명도 조정은 아직 안됩니다(추후 업데이트 예정).
