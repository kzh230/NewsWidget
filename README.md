# NewsWidget
News Widget for Android

## 소개
가볍고 빠른 뉴스 위젯을 구현하는 안드로이드 앱입니다.
기존의 뉴스 위젯들과 달리, 가볍고 심플해서 부담 없이 사용 할 수 있습니다.

## 설치법
1. Releases에서 최신 버전을 다운로드 합니다.
2. NewsWidget_v.1.x.apk 파일을 실행하여 설치합니다(.apk 파일 설치 시 디바이스의 보안을 위한 차단을 해제 할 필요가 있습니다).
3. 바탕 화면을 길게 눌러 NewsWidget 이름의 위젯을 찾아 고정하고 크기를 조절합니다.

## 사용법
1. 위젯 화면의 아무 곳이나 터치하면 바로 뉴스가 바뀌며, 자동 바뀜 주기는 1분입니다.
2. 우측 상단의 "뉴스 보기 >>"를 누르면 구글 뉴스 앱이나 기본 웹브라우저가 열리며 해당 뉴스를 보여주고, 관련된 뉴스도 검색해서 보여줍니다.
3. 뉴스 목록은 'Google News RSS'로 받으며, 15분 간격으로 갱신됩니다.
4. 슬립 모드에서는 RSS 목록과 위젯 모두 갱신되지 않습니다.

## v1.5 Update
1. 위젯 뉴스의 자동 바뀜 주기를 1분으로 단축하고, 슬립 모드에서는 작동하지 않도록 했습니다.
2. "뉴스 보기 >>" 실행 시 웹브라우저가 중복으로 열리는 문제를 해결했습니다. 
3. 위젯의 Layout을 몇 가지 수정했습니다.
