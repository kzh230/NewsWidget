# NewsWidget
News Widget for Android

## 소개
안드로이드용 뉴스 위젯 앱입니다.
기존의 뉴스 위젯들과 달리, 가볍고 심플해서 부담없이 사용 할 수 있습니다.

## 설치법
1. Releases에서 최신 버전을 다운로드 합니다.
2. NewsWidget_v.1.x.apk 파일을 실행하여 설치합니다(.apk 파일 설치 시 디바이스의 보안을 위한 차단을 해제 할 필요가 있습니다).
3. 바탕 화면을 길게 눌러 NewsWidget 이름의 위젯을 찾아 고정합니다.
4. 화면의 크기는 조절 가능합니다.

## 사용법
1. 위젯 화면의 아무 곳이나 터치하면 뉴스가 바뀌며, 뉴스 자동 바뀜은 30분입니다(Google 정책에 따른 시간).
2. 우측 상단의 "뉴스 보기 >"를 누르면 구글 뉴스 앱이나 기본 웹브라우저가 열리며 해당 뉴스를 검색해 관련 뉴스들을 보여줍니다.
3. 구글 뉴스 앱을 설치하면 더 편리하게 사용할 수 있습니다.
4. 뉴스 목록은 15분 간격으로 구글 뉴스 홈에서 받아 리셋됩니다.
5. 위젯의 색상 변경이나 투명도 조정은 아직 안됩니다(추후 업데이트 예정).
